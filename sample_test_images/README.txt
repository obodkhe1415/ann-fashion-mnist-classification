Sample test images (Fashion-MNIST official test set)

- 20 images: 2 per clothing class, taken from the 10,000-image test set.
- Each file is a 280x280 PNG (scaled up from 28x28 so it is easy to view).
- labels.csv lists the true class for each file and its index in the test set.

How to use in the notebook (Step 10):
1. Run Step 10, click "Choose Files", and select ONE image from this folder.
2. The model prints its prediction and confidence.
3. Compare with the true class in labels.csv.

Expect about 9 out of 10 correct on average, matching the 87.63% test accuracy.
